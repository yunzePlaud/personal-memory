# PMI Web UI 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `pmi ui`：一个只监听本机的网页，用来浏览和管理记忆、审批待审改动、看磁盘占用、实时查看配置好的 agent 日志。

**Architecture:** 服务端是 `src/pmi/ui/` 下的标准库 HTTP 服务（`ThreadingHTTPServer`），所有读写都通过现有的 `pmi.api.Memory`，身份是 `Actor.owner("ui")`。日志、存储统计、口令、`[ui]` 配置各是一个独立的小模块。前端是 `src/pmi/ui/static/` 下的三个静态文件（HTML + 原生 JS + CSS），用 hash 路由，轮询 JSON 接口。

**Tech Stack:** Python 3.12 标准库（`http.server`、`tomllib`、`secrets`、`hmac`、`webbrowser`）；原生 JS / CSS；pytest。

**Spec:** `docs/superpowers/specs/2026-11-11-pmi-web-ui-design.md`

## Global Constraints

- 不新增任何依赖（`pyproject.toml` 的 dependencies 不变），不用 CDN，不引入 npm 或任何前端构建步骤。
- 服务只绑定 `127.0.0.1`；默认端口 `8765`。
- 每个 `/api/` 请求：`Host` 必须等于 `127.0.0.1:<端口>` 或 `localhost:<端口>`，否则 403，错误码 `forbidden_host`；请求头 `X-PMI-Token` 必须等于口令（用 `hmac.compare_digest` 比较），否则 401，错误码 `unauthorized`。
- 不输出任何 CORS 响应头。`POST` 必须带 `Content-Type: application/json`，body 不超过 65536 字节，且必须是 JSON 对象（空 body 视为 `{}`），否则 400。
- 网页的所有操作都以 `Actor.owner("ui")` 身份执行（操作记录里显示 `owner:ui`）。
- 口令文件：`<home>/data/ui-token`，权限 `0o600`；`pmi backup` / `pmi export` 不包含它。
- `[ui]` 配置段只由 `pmi.ui.config` 解析；`load_settings` 跳过它。
- 界面文字用英文；代码、注释、标识符、错误信息用英文（仓库约定）。
- 默认值：`stale_minutes = 10`；日志末尾 1000 行；日志页每 3 秒轮询；首页每 10 秒轮询；记忆每页 50 条。
- 错误响应格式：`{"error": {"code": str, "message": str, "details": dict}}`。HTTP 状态：`validation` 400、`unauthorized` 401、`policy_denied` 403、`forbidden_host` 403、`not_found` 404、`method_not_allowed` 405、`conflict` 409、`internal` 500（终端打印 traceback，响应里不带内部细节）。
- 前端把服务端数据插入页面时只用 `textContent` / `createElement`，**禁止** `innerHTML`、`insertAdjacentHTML`、`document.write`（记忆和日志里有别人写的文字）。证据链接只在 URL 以 `http://` 或 `https://` 开头时渲染成链接，并带 `target="_blank" rel="noopener noreferrer"`。
- `index.html` 不含内联 `<script>` / `<style>` / `style=` 属性；服务端对所有响应加 `Content-Security-Policy: default-src 'self'`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`Cache-Control: no-store`。
- 测试命令：在仓库根目录 `uv run --frozen --extra semantic pytest -q`，全套测试保持通过。
- 每个 commit message 以会话的 attribution 行结尾（见会话里的 system reminder）。

## Review Focus

1. **bot 正在写半行，或一个中文字符的字节被截在中间**：读日志只返回完整的行，偏移量停在最后一个 `\n` 之后，绝不输出半个字符。→ Task 2 `test_since_never_splits_multibyte`
2. **日志文件很大（几十 MB）**：取末尾 1000 行时从文件尾部按块往回读，不读整个文件；跨块的行要完整。→ Task 2 `test_tail_across_small_blocks`
3. **URL 里是不存在或奇怪的 id**（`/api/memories/mem_nope`、`%2e%2e`）：返回 404 JSON，绝不 500。→ Task 7 `test_bad_ids_are_404`
4. **格式不对的 POST**（非 JSON、JSON 数组、原因为空、body 过大、Content-Type 不对）：返回 400，数据不变。→ Task 7 `test_malformed_posts_change_nothing`
5. **口令文件被清空或权限被放宽**：重新生成口令，并把权限改回 600。→ Task 4 `test_blank_token_file_regenerated`

### Task 2: 日志读取

**Files:**
- Create: `src/pmi/ui/logs.py`
- Test: `tests/test_ui_logs.py`

**Interfaces:**
- Consumes: `LogSpec`（Task 1）
- Produces:
  - `def log_files(spec: LogSpec) -> list[Path]`：展开 `~` 和通配符，只要普通文件，按文件名倒序。
  - `def resolve_log_file(spec: LogSpec, file_name: str) -> Path`：`file_name` 必须等于某个当前匹配文件的 `.name`，否则抛 `NotFoundError`。
  - `def log_status(spec: LogSpec, now: float | None = None) -> dict`：`{"state": "active" | "stale" | "missing", "file": str | None, "modified_at": str | None, "age_seconds": int | None}`，依据最新文件（`log_files(spec)[0]`）的 mtime；`age <= stale_minutes * 60` 为 `active`。
  - `def read_tail(path: Path, max_lines: int = 1000, block_size: int = 65536) -> dict`：`{"text": str, "offset": int, "size": int, "modified_at": str, "reset": False}`
  - `def read_since(path: Path, offset: int) -> dict`：键同上；`offset > size` 时 `reset=True`，返回 `read_tail(path)` 的结果。
  - 时间格式统一为 UTC `YYYY-MM-DDTHH:MM:SSZ`。
  - "完整的行"：`text` 只包含到最后一个 `\n` 为止的内容，`offset` 是该 `\n` 之后的字节位置；按 UTF-8 解码，`errors="replace"`。

```python
import os, time
import pytest
from pmi.errors import NotFoundError
from pmi.ui.config import LogSpec
from pmi.ui.logs import log_files, log_status, read_since, read_tail, resolve_log_file


def spec(d, **kw):
    return LogSpec(name="bot", path=str(d / "session-*.log"), **kw)


def test_files_sorted_newest_name_first(tmp_path):
    for n in ("session-2026-11-10.log", "session-2026-11-11.log", "other.txt"):
        (tmp_path / n).write_text("x\n")
    assert [p.name for p in log_files(spec(tmp_path))] == ["session-2026-11-11.log", "session-2026-11-10.log"]


def test_tilde_expanded(tmp_path, monkeypatch):
    monkeypatch.setenv("HOME", str(tmp_path))
    (tmp_path / "logs").mkdir()
    (tmp_path / "logs" / "a.log").write_text("x\n")
    assert [p.name for p in log_files(LogSpec("bot", "~/logs/*.log"))] == ["a.log"]


@pytest.mark.parametrize("bad", ["../secret.log", "other.txt", "x/../session-1.log", "", "session-9.log"])
def test_resolve_rejects_names_outside_matches(tmp_path, bad):
    (tmp_path / "session-1.log").write_text("x\n")
    (tmp_path / "other.txt").write_text("x\n")
    with pytest.raises(NotFoundError):
        resolve_log_file(spec(tmp_path), bad)


def test_status_states(tmp_path):
    s = spec(tmp_path)
    assert log_status(s)["state"] == "missing"
    f = tmp_path / "session-1.log"
    f.write_text("x\n")
    now = time.time()
    os.utime(f, (now - 60, now - 60))
    st = log_status(s, now=now)
    assert st["state"] == "active" and st["file"] == "session-1.log" and 59 <= st["age_seconds"] <= 61
    os.utime(f, (now - 11 * 60, now - 11 * 60))
    assert log_status(s, now=now)["state"] == "stale"


def test_tail_returns_last_complete_lines(tmp_path):
    f = tmp_path / "a.log"
    body = "".join(f"line {i}\n" for i in range(1500))
    f.write_text(body + "partial")
    out = read_tail(f, max_lines=1000)
    assert out["text"].splitlines() == [f"line {i}" for i in range(500, 1500)]
    assert out["offset"] == len(body.encode())


def test_tail_across_small_blocks(tmp_path):
    f = tmp_path / "a.log"
    lines = [("行" * (i % 7)) + f" entry {i}" for i in range(3000)]
    f.write_text("\n".join(lines) + "\n")
    assert read_tail(f, max_lines=1000, block_size=97)["text"].splitlines() == lines[-1000:]


def test_since_returns_only_new_complete_lines(tmp_path):
    f = tmp_path / "a.log"
    f.write_text("a\n")
    off = read_tail(f)["offset"]
    with f.open("a") as h:
        h.write("b\nc")
    out = read_since(f, off)
    assert out["text"] == "b\n" and out["offset"] == off + 2 and not out["reset"]
    with f.open("a") as h:
        h.write("\n")
    assert read_since(f, out["offset"])["text"] == "c\n"


def test_since_never_splits_multibyte(tmp_path):
    f = tmp_path / "a.log"
    f.write_bytes("第一行\n".encode())
    off = read_tail(f)["offset"]
    rest = "第二行\n".encode()
    with f.open("ab") as h:
        h.write(rest[:-2])
    out = read_since(f, off)
    assert out["text"] == "" and out["offset"] == off
    with f.open("ab") as h:
        h.write(rest[-2:])
    assert read_since(f, off)["text"] == "第二行\n"


def test_since_resets_when_file_shrinks(tmp_path):
    f = tmp_path / "a.log"
    f.write_text("new\n")
    out = read_since(f, 10_000)
    assert out["reset"] and out["text"] == "new\n"


def test_invalid_utf8_replaced(tmp_path):
    f = tmp_path / "a.log"
    f.write_bytes(b"ok\n\xff\xfe bad\n")
    text = read_tail(f)["text"]
    assert "ok" in text and "�" in text
```

import os, tarfile
from pmi import Memory
from pmi.ui.token import load_or_create_token, token_path


def mode(p):
    return p.stat().st_mode & 0o777


def test_token_created_private(paths):
    t = load_or_create_token(paths)

def test_token_reused(paths):
